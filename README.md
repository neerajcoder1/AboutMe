# Neeraj Gahlout - Full-Stack Web Developer Portfolio

Welcome to the source code of my personal portfolio website! 🚀

This is a highly interactive, beautifully animated digital workspace showcasing my journey, skills, and projects as a Full-Stack Web Developer. The design emphasizes a clean, modern aesthetic with a focus on immersive user experiences using Aceternity UI, Tailwind CSS, and Framer Motion.

## 🌟 Key Features

- **Immersive 3D Assistant**: Features "Robert," a fully interactive 3D virtual assistant integrated via Spline.
- **Theme Adapting Design**: Flawlessly transitions between Dark Mode and Light Mode with dynamic color inversions and CSS variable management.
- **Interactive Image Trail**: A custom Framer Motion cursor effect that leaves a beautiful trail of memories as you navigate the gallery.
- **Modern Tech Stack**: Built with React (Vite), Tailwind CSS v4, and modern web APIs.
- **Fluid Animations**: Utilizing Aceternity UI components for meteors, glare cards, and typography animations.

## 🛠️ Built With

- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **Framer Motion**
- **Spline 3D** (@splinetool/react-spline)
- **Lucide React & React Icons**

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/neerajcoder1/AboutMe.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd AboutMe
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Open your browser:**
   Navigate to `http://localhost:5173` to interact with the portfolio.
